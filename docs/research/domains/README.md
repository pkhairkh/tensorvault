# Domain Research

> Deep research passes across 5 mathematical domains. Each file is a
> standalone literature review with formal definitions, theorems, and
> citations.

## The 5 pillars

| Pillar | Document | Key question it answers |
|--------|----------|------------------------|
| I | [information-theory.md](./information-theory.md) | How do we compress and encode data optimally? |
| II | [spectral-graph-theory.md](./spectral-graph-theory.md) | How do we partition and join data efficiently? |
| III | [probability-and-sketching.md](./probability-and-sketching.md) | How do we estimate and guarantee accuracy? |
| IV | [optimization-theory.md](./optimization-theory.md) | How do we plan and place data optimally? |
| V | [category-theory.md](./category-theory.md) | How do we evolve schemas safely? |

## Cross-cutting themes

These 5 domains are synthesized in [../math-foundations.md](../math-foundations.md)
into 5 cross-cutting themes:

1. **Universal coding length** as the unifying objective
2. **(ε, δ) contract** as the SQL surface
3. **Kingman's formula** as the tier-latency cost model
4. **Spectral methods** unify partitioning, mixing, and sketching
5. **Linear types** enforce protocol boundaries
